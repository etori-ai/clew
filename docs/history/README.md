# History

Frozen records of how the project got here. They are not instructions and nothing is added to them
([D105](../decisions/D105-the-repository-explains-itself-without-a-handover-file.md)). A path, a number or a plan in
these files is that of the day it was written; much of what they describe has since been renamed, replaced or removed.

| File | What it is |
|---|---|
| [handover.md](handover.md) | The handover written on 2026-11-03 for the first build session, and amended until 2026-11-11: the state after the first sessions, the first decisions as a table, the first use case, the first interface principles and the first repository layout. |
| [session-log.md](session-log.md) | One note per working session from 2026-11-03 to 2026-11-11: what was asked, what was built, what was verified and what was left. About 450 KB; search it, do not read it through. |

Both were one file, `HANDOVER.md`, at the repository root. Older decisions and reviews that say "HANDOVER.md" or "the
handover" mean these two files; "section 9" is the session log and "section 3" was the licence record.
