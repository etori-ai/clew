# Licence record

Clew is open source and is shared with other municipalities and governments, so nothing it needs to build, run or test may be closed. The rule is in [CLAUDE.md](../../CLAUDE.md) under "Open source, always": every dependency carries an OSI-approved licence, and the licence is checked before a version is pinned.

## How to add an entry

1. Check the licence before pinning: `npm view <package>@<version> license` for a package, the project or image licence for a Docker service.
2. Add an entry at the top of the record below, in the change that adds, replaces or removes the dependency: the date, what the change was for, each package or image with its exact version and licence, and how it was checked.
3. A change that touches no dependency needs no entry.
