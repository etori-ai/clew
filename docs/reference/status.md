# Implementation status

Reviewed against the working tree on 2026-11-09, including the reliability roadmap implementation and the first jobs across systems. The entries on identity, people, talks, work, the calendar follow-up, remote connectors, connectors, the shared header and operations were checked against the code again on 2026-11-13, with the fixes of the [review of users and the organisation](../reviews/2026-11-12-users-the-organisation-and-the-guides-in-two-rounds.md). This is a checkout-level guide, not a release compatibility promise. The linked code/tests are the evidence to inspect; an ADR's recorded status is design history, not a feature flag. The [acceptance matrix](reliability-acceptance.md) distinguishes implementation from verified scenarios and outstanding release gates.

To change an entry, edit its page. A new entry goes on the page for its area and gets a link in the table above; a one-screen adjustment is recorded in the entry of its page ([D102](../decisions/D102-a-decision-is-provisional-until-something-outside-the-repository-has-tested-it.md)).

Where each surface opens, its address, close target and focus, is the [interface spaces](interface-spaces.md) reference ([D112](../decisions/D112-the-interface-is-rebuilt-on-astryx-templates-a-queue-one-detail-shape-one-panel.md)); the entries here say what of it works and what has been run.

What the product manager's prototype asks for, and whether the architecture carries each item, is kept in [prototype parity](prototype-parity.md). When an entry here changes what a row there says, change the row in the same commit.

## How to read the decision history

Eleven numbers name two records each: D37–D39, D44–D46, D85, D96 and D99–D101. Use full filenames: D37 dependencies differs from D37 header logo; D38 declared views differs from D38 municipal branding; D39 landing alignment differs from D39 compact header. D44 covers both connector authority and the administration check result; D45 covers approved execution intent and administration navigation; D46 covers committed browser revisions and the default theme. The five later pairs:

- D85: [capabilities mapped from provisioned groups](../decisions/D85-capabilities-are-mapped-from-provisioned-groups-in-clew.md) and [DBOS Transact as the durable engine](../decisions/D85-dbos-transact-replaces-temporal-as-the-durable-engine.md).
- D96: [a key written wrong is refused at the SCIM boundary](../decisions/D96-a-key-written-wrong-is-refused-at-the-scim-boundary.md) and [talks, the first owned domain](../decisions/D96-talks-is-the-first-owned-domain-the-round-and-action-points-behind-a-profile.md).
- D99: [the unit tree pushed over SCIM](../decisions/D99-units-form-a-tree-pushed-over-scim-and-a-manager-works-with-their-direct-reports.md) and [an unresolved job step](../decisions/D99-an-unresolved-job-step-reaches-a-person-and-is-finished-forward.md).
- D100: [the narrowed vision](../decisions/D100-the-vision-is-narrowed-to-what-clew-can-keep-today.md) and [the paged people list](../decisions/D100-the-people-list-is-read-a-page-at-a-time-and-narrowed-on-the-server.md).
- D101: [the provisioner's order](../decisions/D101-a-provisioner-pushes-the-organisation-first-and-adds-before-it-removes-and-a-unit-belongs-to-one-organisation.md) and [the first real integration, Nextcloud's Approval app](../decisions/D101-the-first-real-integration-is-nextclouds-approval-app-and-new-surface-waits-for-it.md).

The [generated index](../decisions/README.md) and [context map](../context.json) retain every record and its original status without renumbering.

The practical integration changes are D21/D22 (independent connector services and terminology), D23 (database governance), D38 declared views (Clew renders the UI), and D44 (protocol 2 authority).
