# Review: Astryx 0.7.7 to 0.7.12, what is new and what it changed here · 2026-11-10

Date: 2026-11-10

Reviewed: `@astryxdesign/core`, `@astryxdesign/cli` and `@astryxdesign/theme-neutral` 0.7.12 (published 2026-11-10),
from the packages' own `CHANGELOG.md` for 0.7.8 to 0.7.12 and from running Clew on them.
Status: upgraded; four regressions found and fixed; see Outcome for what was verified and what was not

## Question

The product owner asked for Astryx to be updated and for a look at what is new, in the same session that moved the
installation's theme into an uploaded file (D98).

## What is new that matters to Clew

**Theming.**

- A runtime `Theme` keeps its injected CSS until the last `Theme` using that theme unmounts (0.7.12). Clew's themes
  are runtime themes, and D98 nests a candidate theme in the page for the preview, so this is the behaviour it needs.
- The stock dark `--color-accent` changed (0.7.9). Clew's base extends Neutral, which sets its own accent, and
  `THEME_BASE_COLORS` is held to the resolved theme by a unit test, which passes.
- The root `Theme` scales type with iOS Dynamic Type and Android's preferred text scale (0.7.12).
- `defineTheme({ componentIcons })` slots (0.7.9), a `--duration-exit` token (0.7.8).
- Nothing new for importing a theme from a standard token file, for palettes or for `resolveThemeTokens`. The mapping
  from a Design Tokens file to `defineTheme` is Clew's own (D98).

**Touch targets.** Button and IconButton get a 44 px touch band (0.7.11), SegmentedControl a 44 px target (0.7.10),
List rows, CheckboxInput, RadioList options and ButtonGroup grow toward 44 px (0.7.9). Clew's own coarse-pointer
adaptation in `packages/ui/src/theme.ts` (control sizes and three component minimum heights) was written because 0.7.7
had none of this. It is left in place: removing it is a change to check on a phone, not a side effect of an upgrade.

**The docked composer.** `ChatLayout` keeps its composer above the on-screen keyboard (0.7.12), and with a `scrollRef`
the newest message rests above the dock. Clew's `scrollPaddingBottom` override on `chat-layout` (D31) is for a
focused control under the dock and is still needed.

**Other additions.** List reordering and animated row changes, Table rendering only its visible rows, other calendar
systems in Calendar and the date inputs, `timezoneID` on Timestamp, delays on `DropdownMenuSubMenu`. None is used yet.

**Still missing** (the gaps Clew's decisions record): a general image component (D37), a `max-height` on
ScrollableArea, marking days that hold events in Calendar (D32), a gray Badge and an outlined status Card (the theme
adds both as variants), a colour input and an import of a token file (D98).

## What changed behaviour

- **Toasts are announced from the text Astryx can read in the body's element children** (0.7.12). Before, the toast
  card was itself a live region. Clew's completion toast passed its words as a prop of `CompletionFeedback`
  (`useAdminAction` in `apps/web/src/mutations.ts`), which is drawn but, from 0.7.12, never spoken: every "Sparat"
  on the administration pages went silent for a screen reader (WCAG 4.1.3). **Fixed:** `CompletionFeedback` takes its
  title as `children` and `useAdminAction` passes it so. Found by the new page's announcement test.
- **A disabled Button has `aria-disabled="true"` and no native `disabled`** (0.7.12), and stays a focus stop. The
  review overlay chose where a step's focus goes by reading `button.disabled`, which is now always false, so a step
  with nothing to approve yet put the focus on the disabled Attestera instead of the document's heading. **Fixed** in
  `apps/web/src/components/review-overlay.tsx`, which reads both. Playwright's `toBeDisabled()` understands
  `aria-disabled`, so the specs needed no change.
- **A Popover's content is drawn inside the theme of its trigger.** The reminder bell stands in the header's band
  (D88), whose theme turns text white for a dark ground; its list came out as white words on the popover's light
  ground (axe: colour contrast). **Fixed** in `apps/web/src/components/reminders.tsx`: the content is wrapped in the
  page's theme, a nested `Theme` as the band is. Anything else opened from the band needs the same care.
- **A `LayoutPanel` with a resizable region slides closed and open** (0.7.12). `todo.spec.ts` measured the fold
  button's place the moment after the press; it now waits for the motion to end.
- Spinner's role is `progressbar`, not `status` (0.7.9), including the hidden ones inside Button and TextInput.
- Dialog's initial focus goes to the dialog's title (0.7.12); a closed Popover leaves no hidden `role="dialog"`; a
  scrolling `LayoutContent` or `LayoutPanel` is a group named "Content" (0.7.9); Calendar's weekday headers are
  abbreviated (0.7.8); Collapsible wraps its region's children in one element (0.7.11).
- One codemod, for Tokenizer's `presentation` (0.7.8). Clew does not use Tokenizer; `astryx upgrade --from 0.7.7`
  reports nothing to change in `packages/ui`.

## Outcome

- Pins moved to 0.7.12 in the root, `packages/ui` and `packages/site-header`; licences checked (MIT); `astryx doctor`
  passes.
- `bun run check` is green on 0.7.12.
- The WCAG suite was run once on 0.7.12, every spec but `views.spec.ts`, which Playwright cannot load: 555 tests, 378
  passed, 162 skipped, 15 failed. The same nine spec files were then run on 0.7.7 without this session's changes: 11
  of the 15 fail there too (`calendar.spec.ts:182`, four in `menu.spec.ts`, `optimistic.spec.ts:15`, two in
  `reliability.spec.ts`, two in `tools.spec.ts`, `touch.spec.ts:39`) and are not from the upgrade. The four that
  were (two in `shell.spec.ts`, `documents.spec.ts:191`, `todo.spec.ts:176`) are the three fixes above; their three
  spec files pass again, 39 of 39.
- Not done: a manual pass on a phone for the touch-target and keyboard changes, and a screen-reader pass.
