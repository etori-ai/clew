# Follow-up review of the prototype shell and registers

This review follows the 16 findings on [PR 83](https://github.com/etori-ai/clew/pull/83) at `61e4ef2f`. The second pass traced the host and embedded header separately, followed query and route state across transitions, and checked new and previously saved appearances. The regression scenarios below use the same entry points as the product.

| Finding | Change and regression scenario |
|---|---|
| 1. Going home lost a question draft | The web host lets React Router handle its own home address. Other sites keep document navigation, including an intranet on the same origin. Type a draft, leave Hem, and return through the logo, the pages row or the connector's Start link. [Hem](../../tests/a11y/hem.spec.ts) · [Header](../../tests/a11y/header.spec.ts) |
| 2. The phone menu outlived a navigation | The header follows the host history entry. Choose Att göra from a filtered queue or reselect the current page. The address and the drawer must both reflect the selection. [Header](../../tests/a11y/header.spec.ts) |
| 3. The queue stopped measuring its width | The queue observes each layout element for its entire mounted lifetime. Open a wide deep link, close the reading pane, narrow the viewport and follow another item to its own page. [Queue](../../tests/a11y/queue.spec.ts) |
| 4. Fråga AI pointed to an absent field | The shell uses the conversation provider's open state. Hold the first response on Hem and verify the corner disappears while the transcript is already visible at `/`. The conversation register still offers the corner. [Shell](../../tests/a11y/shell.spec.ts) |
| 5. Hem's field lost its focus indicator | The pill draws a real outline. The keyboard test compares focus and blur in both appearances, in forced colours and with an installation whose info colour matches the card. The common keyboard walk checks that outline. [Keyboard](../../tests/a11y/keyboard.spec.ts) |
| 6. A failed refresh hid the reminder count from assistive technology | The bell includes the known count and the update error in its accessible name. The test fails a refresh after loading two reminders, checks the visible badge and reads the cached list. A separate case covers a failed first read and retry. [Shell](../../tests/a11y/shell.spec.ts) |
| 7. An empty search removed its field | The single-unit register keeps the field in its card when the result is empty. Add a character that hides the last match, then press Backspace without moving focus. Resetting the filter returns focus to the same field. [Personal](../../tests/a11y/staff.spec.ts) |
| 8. Today's deadlines counted as overdue | The row badge and queue total share an open item's calendar deadline. Test yesterday, today and tomorrow across Stockholm midnight, along with a closed item and a reminder without a deadline. [Work rows](../../apps/web/tests/work-row.test.ts) · [Queue](../../tests/a11y/queue.spec.ts) |
| 9. A failed first read showed four zeroes | The queue shows totals once there is a usable snapshot. Tests distinguish a failed initial read, a source that has never answered and a source with an earlier successful read. Optimistic writes and rollbacks preserve source and delivery metadata. The filtered card reports the number of matching rows. [Queue](../../tests/a11y/queue.spec.ts) · [Cache](../../tests/unit/web-thread-cache.test.ts) |
| 10. Membership in two units counted as two people | The staff figure and subtitle count distinct Clew person keys. Group rows retain each membership. [Staff model](../../apps/web/tests/staff-model.test.ts) · [Personal](../../tests/a11y/staff.spec.ts) |
| 11. The fourth staff view disappeared from the overview | The register considers every configured view with an available result. A fixture puts a need in the fourth view and checks its count and destination. [Personal](../../tests/a11y/staff.spec.ts) |
| 12. A saved theme could draw invisible badges | The contract validates the blue and green text on their tinted backgrounds in each appearance. Existing saved themes keep their backgrounds and get readable text where needed. Tests exercise new uploads, partial overrides and legacy reads. [Theme file](../../tests/unit/theme-file.test.ts) · [Branding](../../tests/unit/branding.test.ts) |
| 13. A pale band could hide the logo | The shared header chooses a logo for its actual background. Its tests cover an installation's two logo variants, a single asset, the connector's supplied white mark on a pale band, and the intranet embed. [Branding](../../tests/a11y/branding.spec.ts) · [Header](../../tests/a11y/header.spec.ts) · [Embed](../../tests/a11y/site-header.spec.ts) |
| 14. Buttons rendered at weight 700 | The button rule uses the theme's heading weight, which resolves to 800. [Branding](../../tests/unit/branding.test.ts) |
| 15. The embed omitted font subsets | The web app and embed import the same pinned Raleway stylesheet. The browser fixture loads the production embed and asks for Latin, Cyrillic and Vietnamese glyphs. [Embed](../../tests/a11y/site-header.spec.ts) |
| 16. Two instructions claimed visual precedence | The contributor rules, canvas guide and older decisions point to D130 for appearance and layout. D126 governs destinations, panes, actions and focus. [Canvas guide](../reference/design-canvases.md) · [Interface spaces](../reference/interface-spaces.md) |

The second pass found two more cases on the same paths. A keyboard-focused control can move under Fråga AI after a scroll or resize. The corner now measures again on those events and the shell test keeps focus on the same link throughout. The intranet connector supplies a white mark intended for dark ground. The header preserves that ground when the installation chooses a pale band or the browser forces its own colours. [Shell](../../apps/web/src/components/shell/assistant-corner.tsx) · [Header](../../packages/site-header/src/site-header.tsx)

The targeted Bun run passed 158 tests across 12 files covering work rows, staff, the thread cache, navigation and appearance. TypeScript and the documentation link check passed. The keyboard and accessible-name cases have automated browser coverage. A manual screen-reader pass remains open.
